# AID2.1 - Entity-Component-System Architecture

Практическая работа №2: Реализация ECS-архитектуры и визуализация объектов

## Описание

Этот проект демонстрирует реализацию полноценной Entity-Component-System (ECS) архитектуры для игрового движка с использованием DirectX 12 и C++17.

## Реализованные возможности

### ECS Ядро
- **Entity** - уникальные идентификаторы объектов (uint32_t)
- **Component** - POD структуры данных
- **System** - логика обработки компонентов
- **World** - центральный реестр сущностей и компонентов

### Компоненты
- **Transform** - позиция, вращение (углы Эйлера), масштаб
- **Tag** - имя объекта
- **MeshRenderer** - тип примитива (треугольник/квадрат/куб), цвет
- **Hierarchy** - иерархия родитель-потомок с поддержкой мировых трансформаций
- **Camera** - компонент камеры с FOV, near/far planes, FPS управлением

### Системы
- **RenderSystem** - отрисовка всех сущностей с Transform и MeshRenderer
- **CameraSystem** - управление камерой (WASD + мышь), обновление View/Projection матриц
- Поддержка иерархических трансформаций

### Рендеринг
- DirectX 12 адаптер с поддержкой:
  - Треугольников
  - Квадратов
  - 3D кубов
  - Матриц Model-View-Projection
  - Цветовой модуляции
  - Depth buffer

### Демонстрационная сцена
- 5+ объектов с разными трансформациями и цветами
- Вращающийся куб в центре
- Движущийся треугольник
- Статичные объекты
- Иерархия: родительский куб с двумя дочерними объектами

1. Откройте `AID2.1.sln` в Visual Studio 2022

3. Выберите платформу x64
4. Нажмите F5 для сборки и запуска

## Архитектурные особенности

### ECS Pattern
- Разделение данных (компоненты) и логики (системы)
- Композиция вместо наследования
- Гибкое добавление/удаление компонентов
- Эффективная обработка множества объектов

### Иерархия объектов
- Компонент Hierarchy для связи родитель-потомок
- Рекурсивное вычисление мировых матриц
- Локальные трансформации относительно родителя

### Рендеринг
- Абстракция графического API через RenderAdapter
- Поддержка матриц Model-View-Projection
- Batch rendering через ECS систему
- Depth testing для корректного отображения 3D

## Технические детали

### Математика
- DirectXMath для векторов и матриц
- XMFLOAT3 для позиции, вращения, масштаба
- XMFLOAT4 для цвета (RGBA)
- XMMATRIX для трансформаций

### Хранение компонентов
- std::unordered_map<EntityId, Component> для каждого типа
- std::any для type-erasure
- std::type_index для идентификации типов

### Производительность
- Минимальное копирование данных
- Эффективный поиск компонентов
- Batch обработка в системах
