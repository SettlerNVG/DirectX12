# AID5.1 - WYSIWYG Editor with Dear ImGui

## Описание
AID5.1 - это WYSIWYG (What You See Is What You Get) редактор, построенный на базе Dear ImGui и DirectX 12. Проект представляет собой полнофункциональный редактор сцен с поддержкой Entity-Component-System (ECS), физики, рендеринга и интуитивного пользовательского интерфейса.

## Основные возможности

### 🎨 Редактор интерфейса
- **Scene Hierarchy** - иерархия объектов сцены с возможностью выбора
- **Inspector** - детальное редактирование свойств выбранного объекта
- **Viewport** - 3D окно просмотра сцены
- **Statistics** - статистика производительности и сцены
- **Asset Browser** - браузер ресурсов проекта
- **Console** - консоль вывода логов и команд
- **Toolbar** - панель инструментов с режимами Play/Edit

### 🎮 Режимы работы
- **Edit Mode** - режим редактирования сцены
- **Play Mode** - режим воспроизведения с активной физикой

### 🔧 Gizmo манипуляторы (ImGuizmo)
- **Translate** - перемещение объектов (Q)
- **Rotate** - поворот объектов (W)  
- **Scale** - масштабирование объектов (E)
- **World/Local** - переключение координатных систем (R)
- **Snap** - привязка к сетке

### 🏗️ ECS архитектура
- **Transform** - позиция, поворот, масштаб
- **Tag** - имя объекта
- **MeshRenderer** - визуальное представление
- **Rigidbody** - физическое тело
- **Collider** - коллайдер (Box/Sphere)
- **Camera** - камера

### ⚡ Физическая система
- Гравитация и столкновения
- Box и Sphere коллайдеры
- Триггеры
- Оптимизация "спящих" объектов
- Контроль контакта с землей

### 🎯 Системы
- **PhysicsSystem** - обработка физики
- **RenderSystem** - рендеринг объектов
- **CameraSystem** - управление камерой
- **DebugRenderSystem** - отладочная визуализация

## Технические требования

### Зависимости (vcpkg)
```json
{
  "dependencies": [
    {
      "name": "imgui",
      "features": [
        "dx12-binding",
        "win32-binding", 
        "docking-experimental"
      ]
    },
    "imguizmo"
  ]
}
```
### Системные требования
- Windows 10/11
- Visual Studio 2019/2022
- DirectX 12 совместимая видеокарта
- vcpkg для управления зависимостями

## Установка и сборка

### 1. Установка vcpkg (если не установлен)
```bash
git clone https://github.com/Microsoft/vcpkg.git
cd vcpkg
.\bootstrap-vcpkg.bat
.\vcpkg integrate install
```

### 2. Установка зависимостей
```bash
vcpkg install imgui[dx12-binding,win32-binding,docking-experimental]:x64-windows
vcpkg install imguizmo:x64-windows
```

### 3. Сборка проекта
1. Откройте `AID5.1.sln` в Visual Studio
2. Убедитесь что выбрана конфигурация `Debug x64` или `Release x64`
3. Соберите проект (Ctrl+Shift+B)

## Управление

### Камера (в режиме Edit)
- **WASD** - перемещение
- **Мышь** - поворот камеры (зажать правую кнопку)
- **Shift** - ускорение движения
- **Ctrl** - замедление движения

### Gizmo горячие клавиши
- **Q** - режим перемещения
- **W** - режим поворота
- **E** - режим масштабирования
- **R** - переключение World/Local

### Интерфейс
- **Space** - Play/Stop режим
- **F** - фокус на выбранном объекте
- **Delete** - удалить выбранный объект
