е# Game Engine AID1.1

Минимальный рабочий каркас игрового движка с поддержкой игрового цикла и визуализации графического вывода через адаптер рендеринга DirectX 12.

## Описание проекта

Этот проект реализует базовый игровой движок согласно техническому заданию практического занятия №1.

При запуске приложения автоматически открывается консольное окно с цветными логами для отладки и мониторинга работы движка.

### Реализованные компоненты:

1. **Класс Application** - управление жизненным циклом приложения
   - Инициализация
   - Запуск основного цикла
   - Завершение программы

2. **Система управления состояниями игры**
   - MenuState - состояние меню (автоматически переключается на игровое состояние через 3 секунды)
   - GameplayState - игровое состояние с управлением объектом
   - StateManager - менеджер для управления состояниями

3. **Расчёт deltaTime**
   - Высокоточный таймер на основе std::chrono
   - Подсчет FPS
   - Плавность анимаций независимо от частоты кадров

4. **Система логирования**
   - Запись в файл engine.log
   - Вывод в консольное окно с цветным форматированием
   - Различные уровни логирования (INFO - зеленый, WARNING - желтый, ERROR - красный, DEBUG - голубой)
   - Автоматическое открытие консоли при запуске приложения

5. **Адаптер рендеринга (RenderAdapter)**
   - Интерфейс для абстракции графического API
   - Реализация D3D12Adapter для DirectX 12
   - Возможность легкой замены графического API

6. **Отрисовка тестовых примитивов**
   - Рендеринг треугольника
   - Поддержка трансформаций (перемещение, масштабирование, вращение)

### Дополнительное задание (реализовано):

**Интеграция ввода с клавиатуры и мыши:**

- **Клавиатура:**
  - Стрелки вверх/вниз → вертикальное перемещение объекта
  - Стрелки влево/вправо → горизонтальное перемещение объекта
  - ESC → возврат в меню (из игры) или выход (из меню)

- **Мышь:**
  - Левая кнопка мыши → масштабирование объекта (в игре) / клик по кнопкам (в меню)
  - Правая кнопка мыши → вращение объекта вокруг своей оси
  - Средняя кнопка мыши → сброс масштаба и вращения

**Визуальное меню:**
- Главное меню с визуальными элементами (прямоугольники через DirectX)
- Белый прямоугольник - заголовок "MAIN MENU"
- Зеленый прямоугольник - кнопка "START"
- Серые прямоугольники - подсказки
- Возможность вернуться в меню из игры по ESC

**UI в игре (через DirectX):**
- Панель управления (слева вверху) с цветными иконками
- Информационная панель (справа вверху) с прогресс-барами
- Визуальные индикаторы для Position X/Y, Scale и Rotation
- Нижняя панель статуса с FPS индикатором
- Цветовые индикаторы (зеленый для позиции, желтый/красный для масштаба)
- Все UI элементы отрисованы через DirectX 12

**Консольное окно:**
- Автоматически открывается при запуске
- Цветной вывод логов (зеленый INFO, желтый WARNING, красный ERROR, голубой DEBUG)
- Отображение FPS и DeltaTime
- Логирование всех событий движка

## Требования

- Visual Studio 2022
- Windows 10/11
- DirectX 12 SDK (входит в Windows SDK)
- C++17 или выше

## Сборка и запуск

1. Откройте файл `AID1.1.sln` в Visual Studio 2022
2. Выберите конфигурацию Debug или Release
3. Нажмите F5 для сборки и запуска проекта

## Архитектурные решения

### Паттерн "Состояние" (State Pattern)
Используется для управления различными режимами игры. Позволяет легко добавлять новые состояния и переключаться между ними.

### Паттерн "Адаптер" (Adapter Pattern)
RenderAdapter абстрагирует конкретную реализацию графического API, позволяя легко заменить DirectX на OpenGL или Vulkan без изменения основного кода.

### SOLID принципы
- Single Responsibility: каждый класс отвечает за одну задачу
- Open/Closed: система легко расширяется новыми состояниями и адаптерами
- Dependency Inversion: зависимость от абстракций (RenderAdapter), а не от конкретных реализаций

## Логирование

Все важные события записываются в файл `engine.log` и выводятся в консольное окно с цветным форматированием:
- **INFO** (зеленый) - Инициализация компонентов, смена состояний
- **WARNING** (желтый) - Предупреждения
- **ERROR** (красный) - Ошибки
- **DEBUG** (голубой) - FPS и deltaTime

Консольное окно открывается автоматически при запуске приложения.

## Управление

- **Стрелки** - перемещение треугольника
- **ЛКМ** (зажать) - увеличение масштаба
- **ПКМ** (зажать) - вращение объекта
- **СКМ** - сброс трансформаций
- **ESC** - выход из приложения
