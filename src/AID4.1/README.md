# AID4.1 - Physics & Input System Integration

**Практическая работа №4**: Интеграция физики и системы ввода с визуальной отладкой

## 📋 Описание

Полноценная реализация физической подсистемы (коллизии, гравитация) и системы управления вводом, интегрированных с ECS-архитектурой. Проект включает визуальную отладку физических взаимодействий через RenderAdapter на базе DirectX 12.

## Реализованные возможности

### 🎮 Система ввода (InputManager)
- **Singleton паттерн** для глобального доступа
- **Абстракция устройств ввода** (клавиатура, мышь)
- **Состояния клавиш**: Pressed, Down (в этом кадре), Up (отпущена)
- **Отслеживание мыши**: позиция, дельта движения, колесо
- **Action Mapping**: привязка действий к клавишам
- **Управление курсором**: показать/скрыть, центрирование

### ⚙️ Физическая система (PhysicsSystem)
- **Гравитация**: настраиваемая сила тяжести
- **Rigidbody компонент**: масса, скорость, ускорение, drag, упругость
- **Фиксированный шаг физики** (1/60 сек) для стабильности
- **Интеграция Эйлера** для обновления позиций
- **Кинематические тела**: объекты без физики, но с движением

### 💥 Система коллизий
- **AABB (Box) коллайдеры**: axis-aligned bounding boxes
- **Sphere коллайдеры**: сферические границы
- **Гибридные коллизии**: AABB vs AABB, Sphere vs Sphere, AABB vs Sphere
- **Разрешение коллизий**: 
  - Разделение объектов по нормали
  - Импульсное разрешение с учётом масс
  - Коэффициент упругости (restitution)
- **Триггеры**: коллайдеры без физического отталкивания

### 📡 Система событий (EventBus)
- **Глобальная шина событий** (Singleton)
- **Type-safe подписки** через шаблоны
- **CollisionEvent**: уведомления о столкновениях
- **Расширяемость**: легко добавлять новые типы событий

### 🐛 Debug-визуализация
- **Отрисовка коллайдеров**: AABB и сферы
- **Цветовая индикация**: 
  - Жёлтый - обычные коллайдеры
  - Зелёный - триггеры
- **Переключение по F3**
- **Полупрозрачность** для видимости объектов внутри

### 🎥 Улучшенная система камеры
- **Интеграция с InputManager**
- **FPS-управление**: RMB + мышь для осмотра
- **WASD + QE**: движение в 6 направлениях
- **Shift**: ускорение движения
- **Плавное управление** с учётом deltaTime

### 🎯 Демонстрационная сцена
- **Статичная платформа** (земля)
- **6 падающих объектов** с разными массами и формами
- **Управляемый игроком объект**: стрелки + пробел (прыжок)
- **Реалистичная физика**: гравитация, упругость, трение
- **Счётчик коллизий** в реальном времени

## Архитектурные особенности

### Фиксированный шаг физики
```cpp
// Физика обновляется с постоянной частотой 60 Hz
const float FIXED_TIMESTEP = 1.0f / 60.0f;
```
Это обеспечивает:
- ✅ Стабильное поведение независимо от FPS
- ✅ Предсказуемость симуляции
- ✅ Отсутствие артефактов при низком FPS

### Разделение ответственности
- **PhysicsSystem**: только физика и коллизии
- **InputManager**: только ввод
- **CameraSystem**: только камера
- **DebugRenderSystem**: только отладочная визуализация

### Event-Driven архитектура
```cpp
// Подписка на события
SUBSCRIBE_TO_EVENT(CollisionEvent, [](const CollisionEvent& e) {
    LOG_INFO("Collision detected!");
});

// Публикация событий
PUBLISH_EVENT(CollisionEvent(entityA, entityB, normal, depth));
```

### Action Mapping
```cpp
// Привязка действий к клавишам
input.BindAction("Jump", KeyCode::Space);

// Проверка действия
if (input.IsActionTriggered("Jump")) {
    player.Jump();
}
```

## Технические детали

### Обнаружение коллизий

#### AABB vs AABB
```cpp
bool intersects = 
    (aabb1.min.x <= aabb2.max.x && aabb1.max.x >= aabb2.min.x) &&
    (aabb1.min.y <= aabb2.max.y && aabb1.max.y >= aabb2.min.y) &&
    (aabb1.min.z <= aabb2.max.z && aabb1.max.z >= aabb2.min.z);
```

#### Sphere vs Sphere
```cpp
float distance = length(sphere1.center - sphere2.center);
bool intersects = distance < (sphere1.radius + sphere2.radius);
```

### Разрешение коллизий

#### Импульсное разрешение
```cpp
// Вычисляем импульс
float j = -(1 + restitution) * velocityAlongNormal;
j /= (1/massA + 1/massB);

// Применяем импульс
velocityA += (j / massA) * normal;
velocityB -= (j / massB) * normal;
```

### Интеграция физики (Euler)
```cpp
// Обновление скорости
velocity += (gravity + acceleration) * deltaTime;
velocity *= (1 - drag * deltaTime);

// Обновление позиции
position += velocity * deltaTime;
```

## Производительность

### Текущая сложность
- **Обнаружение коллизий**: O(n²) - brute force
- **Подходит для**: до 50-100 объектов
- **Для больших сцен**: требуется spatial partitioning

### Оптимизации
- Фиксированный шаг физики (60 Hz)
- Минимальное копирование данных
- Эффективное использование SIMD (DirectXMath)

## 🐛 Известные ограничения

1. **Производительность**: O(n²) проверка коллизий - не подходит для >100 объектов
2. **Точность**: Euler интегрирование может накапливать ошибки
3. **Стабильность**: Stacking объектов может быть нестабильным
4. **Визуализация**: Debug-отрисовка использует обычные кубы вместо wireframe
